## 1. 研究对象与能力边界

本方法不是静态点云压缩，也不是任务策略的一部分。它学习静态手型定义与当前关节构型到整手当前碰撞表面的确定性映射，以及该表面沿每个活动关节坐标的局部变化：

$$
(\mathfrak m,q)
\longmapsto
\mathcal S_{\mathfrak m}^{h}(q).
$$

保留表征固定为：

$$
z^{geo}
=
\left(
Z^{(0)},
\{z_i^{(1)}\}_{i=1}^{N_J}
\right),
$$

其中 $Z^{(0)}\in\mathbb R^{N_E\times D_0}$ 表示当前整手零阶几何状态，$z_i^{(1)}\in\mathbb R^{D_1}$ 表示沿第 $i$ 个关节方向的运动学—几何局部响应。二者的隐藏宽度跨手型固定且无物理单位。

`cross-embodiment` 表示模型参数、网络结构和输出类型不绑定具体手型；`task-free` 表示 SSL 不读取物体、目标、奖励、动作、接触、历史或策略轨迹。该方法仍然以目标手型的静态几何、拓扑、旋量和物理锚点为条件，因此不应被解释为“不需要 embodiment evidence”。

本阶段不实现 PPO、策略时序、动作分布、奖励、ADR、物体泛化或 sim2real 控制。N000 TCN30 只作为 single-asset 阶段的上游科研语义锚点，不构成本阶段网络继承关系。

## 2. 主线与候选边界

当前唯一实施主线是条件隐式路线：保留编码器只读取当前 $q$ 与静态手型证据，不直接生成或读取当前 posed mesh、当前表面支撑点、最近点、距离、场标签或表面 Jacobian。当前几何、最近点和一阶信息只存在于监督目标侧。

解析直接几何压缩保留为具名候选。若未来激活，它可以读取缓存支撑点经当前 FK 或刚体位姿得到的 current physical points，但本阶段不为它建立与隐式主线同等成熟的资产缓存、数据集、训练器或性能结论。

以下候选只保留接口位置和科学问题，不进入首版主线：粗尺度几何闭包、独立 $D_g$、直接 encoder 切向量、切向量蒸馏、额外 JOINT 自注意力、PyTorch3D 后端、解析直接路线和目标官方手几何适配。

## 3. 包所有权与依赖方向

依赖方向保持：

```text
assets -> robots -> tasks -> distill
```

### 3.1 `assets`

`assets` 拥有版本化资产事实、生成与恢复逻辑、语义 owner lowering、碰撞组成和来源信息。generated sidecar `hand.yaml` 应逐步补齐：

- schema version、资产身份、内容哈希、来源阶段和父级 pre-made root；
- family、handedness、topology registry key、slot map 和 post-mutate provenance；
- `{a}`、`{h}`、单位、$q_{home}$ 和 frame calibration；
- 有序活动关节、parent/child、ancestor、chain depth 和分支信息；
- PALM/JOINT/TIP 实体顺序与 collision component 的唯一 owner；
- primitive/mesh 类型、局部变换、来源路径、watertightness 和几何哈希；
- 每根手指 palm–finger 交界处的语义采样种子，以及 palm physical solid 支撑信息。

sidecar 只保存“这只手是什么”。具体 anchor realization、home surface samples、查询点、Gaussian 带宽、训练 seed 和网络参数不写入资产 sidecar；它们属于由资产哈希和实验配置派生的 SSL 缓存。

当前 generated URDF 家族的共同 home 语义是所有活动关节 $q=0$，手指近似位于统一平面层。该事实必须显式保存为 $q_{home}$，不能依赖缺失字段或任务 pregrasp 推断。未来不遵守该约定的来源必须由其适配器显式提供非零 $q_{home}$。

现有 `source_mode="post_mutate"` 通过绝对路径选择 pre-made mother 的做法是语义债务。资产阶段应建立正式 `pre_made` 或等价的显式来源语义，SSL 不继续复制 workaround。

### 3.2 `robots`

`robots` 消费规范化资产事实，并拥有：

- 严格的批量 $SE(3)$ 前向运动学；
- 当前关节轴 $\omega_i^h(q)$ 与轴上一点 $p_i^h(q)$；
- owner 当前刚体变换 $T_{hg}(q)$；
- 给定 owner-local material point 的解析 point Jacobian；
- 与 URDF importer、IsaacLab articulation pose 的小规模一致性接口。

`robots` 不拥有 surface/query 采样、Gaussian 场、SSL 损失或训练器。

### 3.3 `distill.representations`

`representations` 只消费类型化资产与运动学接口，拥有 physical anchors、home surface samples、查询点、距离、密度、最近点来源、$\kappa/g$、掩码和派生缓存。它不解析 `hand.yaml`、URDF link 名称或 IsaacLab 环境对象。

### 3.4 `distill.models`、`distill.objectives` 与 `distill.ssl`

`models` 拥有 learnable point–anchor encoder、归属体集合编码器、整手主干、零阶/一阶 head 与训练期解码器。`objectives` 拥有 prediction/target/mask/weight 到 scalar loss 的语义。`ssl` 只负责解析实验、在线生成训练批次、优化、检查点、日志与评估编排。

### 3.5 `distill.diagnostics`

`diagnostics` 记录训练动态、固定评估和只读分析，不决定实验候选、不修改 sampler，也不反向参与模型前向。

## 4. 实体、归属体与真实碰撞表面

每个 PALM/JOINT/TIP 物理实体同时是一个 surface owner，实体索引、owner 轴和 SSL decoder owner 轴直接同索引，$G=N_E$。实体不要求与一个原始 URDF link 一一对应；一个实体可以拥有同一刚体上的多个 collision shapes，TIP 可以合并最后活动关节后的固定后代，PALM 可以包含经审核的 fixed root shells。

generated mother `right_t4_i4_m4_r4` 的首版审核映射固定为：

| 角色 | collision pieces | 数量 |
| --- | --- | --- |
| PALM | palm box 与 index/middle/ring 三个 fixed-root shells | 4 |
| JOINT | 16 个活动 revolute joint 的 child-link collision | 16 |
| TIP | 四个活动链末端的 fixed tip mesh | 4 |

所有 collision component 必须恰好被一个实体覆盖。缺失、重复、字符串排序歧义或 fixed descendant 无法审核时 fail closed，不为追求资产数量静默生成标签。

对同一 owner 的 collision solids $\Omega_{g,c}$，物理实体定义为：

$$
\Omega_g
=
\bigcup_{c\in\mathcal C_g}\Omega_{g,c},
\qquad
\mathcal S_g
=
\partial\Omega_g.
$$

被同一 owner 另一 component 完全埋住的原始表面不属于可见 owner skin，应从 surface candidates 中删除。开放凹槽的内侧面仍属于真实碰撞表面并保留；不同 owner 在 home pose 下即使遮挡或相交也不能合并，因为关节运动后这些表面可能重新暴露。

首版不使用 convex hull、近似 box 或 object-size-conditioned closure 替代真实碰撞表面。粗尺度闭包只有在真实 surface 细节被证明确实损害 cross-embodiment 迁移时，才作为独立候选进入实验。

## 5. Physical anchors

### 5.1 语义种子与通用性

每根手指以 palm–finger 交界处的第一个活动 joint frame origin 作为采样分布中心。generated assets 使用 generator mount truth；official LEAP/Allegro 使用版本化 sidecar、URDF graph candidate、collision 可视化和人工审核。种子可以位于 palm solid 外部，anchors 必须从种子邻域与 palm physical solid 的交集中取得。

对第 $j$ 根手指的种子 $m_j^h$，候选采样权重采用随距离衰减并具有有限支撑的形式，例如：

$$
w_j(x)
\propto
\exp\!\left(
-\frac{\|x-m_j^h\|_2^2}{2r_j^2}
\right)
\mathbf 1[\|x-m_j^h\|_2\le R_j].
$$

$r_j$ 与 $R_j$ 必须由 palm projected scale、mount spacing 等无量纲比例定义，不能复制当前 mother box 的绝对毫米数。surface/interior 混合比例、每指 anchors 数和半径由 generated validation probe 选择。

anchors 是坐标 landmarks，不是 contact labels，因此允许位于 palm solid interior。anchor realization 对每个资产固定一次并保存 seed、采样测度、来源种子、surface/interior provenance 和资产哈希；训练 step 不重新生成另一套 anchors。

### 5.2 网络中的等地位集合

所有 $K$ 个 anchors 在网络中地位一致。每个 anchor 的 finger-seed 来源只用于采样 provenance、覆盖诊断和可复现审计，不作为 learned finger ID、role embedding 或优先级输入。

主线把全部 anchors 展平为一个 permutation-equivariant set。对每个 home surface point、query point 或 screw relation，沿完整 $K$ 轴使用共享关系投影与 set attention；不先形成 per-finger anchor summary。两级分段聚合只保留为未来计算候选，不能静默替换主线。

### 5.3 Gauge 与手性

`{h}` 只固定有向 palm normal $n_p=z_h$。点—锚点关系在形成实体 token 前收缩为绕 $n_p$ 的 $SO(2)$ 不变标量，同时必须保留 reflection/chirality 与 JOINT sign 所需的有向信息。首版关系候选至少包含法向高度、面内半径、关系间内积和绕 $n_p$ 的有向叉积；确切 scalar basis 在资产/几何阶段通过成对规范测试冻结。

## 6. Home surface samples

home geometry 表示真实 collision skin，不允许混入 solid interior points。对每个 owner 独立分配 $M_g$ 个样本，在 $q_{home}$ 下从 owner union boundary 按物理面积取候选，并通过确定性近似均匀选择降低三角面密度和重网格顺序的影响。

同一 owner 内按面积采样，避免复杂 mesh 因三角形更密获得更多概率。owner 之间不按总面积竞争 query 或 token 预算，避免 PALM 面积压制 JOINT/TIP。首版 home sample feature 只使用 `{h}` 中的位置，不默认把表面法向加入 retained encoder。

每个 owner 的 $M_g$ 由 surface coverage、最小 Gaussian 带宽、留出重建误差、显存和延迟共同选择。缓存必须保存 owner、component、face/primitive 来源、采样 seed、局部点和 `{h}` home point 之间的可审计变换。

## 7. 构型采样与网络输入

训练直接在每只手的完整 joint-limit hyper-rectangle 中采样当前 $q$，包括限位内自交构型。自交不使逐 owner field 失效；自交严重程度可以作为诊断切片，但首版不通过碰撞过滤改变训练支持域。

采样器先在 $[0,1]^{N_J}$ 内使用 scrambled Sobol 或等价低差异序列，再映射到该手的物理 limits。这个归一化只服务 sampler，不进入 geometry encoder。

物理状态和求导变量始终是 $q$，单位 rad。geometry encoder 读取 $q/\pi$，不按各 joint limits 归一化，也不读取 limits。两个运动学和几何完全相同、只有 limits 不同的手在同一个 $q$ 上必须得到相同 retained geometry representation 和场预测。

网络内任何关于 $q/\pi$ 的 JVP 必须保持从物理 $q$ 到归一化输入的链式路径，使 $\kappa$ 继续以 m/rad 表达。测试显式验证：

$$
\frac{\partial}{\partial q}
=
\frac{1}{\pi}
\frac{\partial}{\partial(q/\pi)}.
$$

训练不读取 policy pregrasp、random-policy rollout、object contact basin 或任务状态访问分布。若未来需要 state-distribution matching，只能作为独立 replay-$q$ 对照，不改变主线成立条件。

## 8. 查询点与在线监督目标

每个 owner 使用自己的查询点集合，逻辑形状为 `[B,G,N_Q,3]`。查询点是训练期 Monte Carlo 轴，不是潜变量，不进入 PPO，也不产生 query token 的永久缓存。

每个 owner 的首版查询比例固定为：

| 查询分层 | 比例 | 作用 |
| --- | ---: | --- |
| 固定 palm/anchor workspace | 50% | 同一查询特征在不同 $q$ 下对应不同 target，强制 $Z^{(0)}$ 携带当前构型 |
| 当前 owner 近表面壳层 | 25% | 学习局部 skin、曲率与小带宽场，但不允许同 owner 共动退化主导训练 |
| 同指邻接 owner/间隙 | 25% | 读取相邻刚体相对运动和中尺度间隙 |

query stratum 只进入 provenance 与 loss weighting，不作为 decoder 输入。每个查询点在本批实际采样的全部显式 sigma 上监督同一个 scalar decoder；不得采用“某类 query 只预测某个 sigma”的 shortcut。

固定 workspace queries 在 `{h}` 中跨 $q$ 复用；随机查询扩大连续覆盖。近表面壳层的内外侧比例当前未冻结，必须在目标后端阶段比较双侧、外侧偏置和内部诊断三种配置，并依据 nearest-source 稳定性、非光滑 mask 比例、留出 field error 和 task-free 解释选择。该选择只能使用 generated validation，不能读取 official held-out 结果调参。

精确表面 $d=0$ 样本只进入单独评估，不作为主训练壳层中心，从而避免 sigmoid 无法有限达到 $\rho=1$、法向不唯一和 Gaussian 一阶导数退化被混成同一问题。

## 9. 物理场与一阶监督

逐 owner unsigned distance 定义为：

$$
d_g(x;q)
=
\inf_{y\in\mathcal S_{\mathfrak m,g}^{h}(q)}
\|x-y\|_2,
$$

单位为 m。对本次显式条件 $\sigma>0$，Gaussian 邻近场为：

$$
\rho_{\sigma,g}(x;q)
=
\exp\!\left(
-\frac{d_g(x;q)^2}{2\sigma^2}
\right).
$$

$\rho$ 是无量纲距离变换，不是 occupancy probability、材料密度或 Gaussian component mixture。decoder 对每个 `(owner,query,sigma)` 输出 scalar，批量输出为 `[B,G,N_Q,N_sigma]`；$N_\sigma$ 是可变数据轴，不是固定输出头宽度。不设置 whole-hand union decoder 或 union loss。若需要联合可视化，只能在共同查询网格上解析取 $\max_g\hat\rho_g$，并标记为派生诊断。

距离灵敏度与场灵敏度为：

$$
\kappa_g(x;q)
=
\nabla_q d_g(x;q),
\qquad
g_{\sigma,g}(x;q)
=
\nabla_q\rho_{\sigma,g}(x;q).
$$

$\kappa_{g,i}$ 单位为 m/rad，$g_{\sigma,g,i}$ 单位为 $\mathrm{rad}^{-1}$。当最近点 $y_g^*$ 唯一且 $i$ 是 owner $g$ 的祖先 JOINT：

$$
\kappa_{g,i}
=
-\hat n_g^\top J_{g,i}^{h},
\qquad
J_{g,i}^{h}
=
\omega_i^h(q)\times\left(y_g^*-p_i^h(q)\right).
$$

非祖先 JOINT 的目标是结构零，不用“未采样”代替。完整 `[B,G,N_Q,N_J]` 与 `[B,G,N_Q,L,N_J]` 只作为逻辑合同；主训练只抽少量 owner–ancestor edges、少量 non-ancestor zeros 或随机方向 JVP。

由链式法则：

$$
g_{\sigma_\ell,g,i}
=
-\frac{d_g}{\sigma_\ell^2}
\rho_{\sigma_\ell,g}
\kappa_{g,i}.
$$

最近面/primitive 切换、medial axis、精确表面、三角形边/顶点和非唯一最近点必须保存来源并单独 mask、降权和统计。被 mask 的困难样本不能从报告中消失。

共同缩放 geometry、query、anchors 与 $\sigma$ 时，$d$ 与 $\kappa$ 按长度缩放，$\rho$ 与 $g$ 不变。只缩放 geometry 而保持米制 $\sigma$ 时，$\rho$ 必须变化。首版不引入显式 $z^{metric}$；metric side channel 只在尺度读取探针失败后进入候选。

## 10. 网络主线

### 10.1 点—锚点共享编码器

home surface point 与 query point 使用同一个 point–anchor relation projection 和同一个沿 $K$ 的 set attention。旋量—锚点关系使用独立属性投影，但同样沿实际 $K$ 聚合到固定宽度 $f_i^{screw}$，不把 $K$ 传播到整手主干或一阶 head。

不能对全部物理表面点执行完整自注意力。主线顺序固定为：

```text
每个点沿 K 个等地位 anchors 聚合
-> 每个 owner 沿 M_g 个表面点聚合
-> 约 N_E 个实体 token 做整手上下文化
```

### 10.2 实体输入

每个实体 token 由以下属性独立编码后拼接：当前 $q/\pi$、固定宽度 $f_i^{screw}$、home geometry feature 与 PALM/JOINT/TIP 角色。PALM/TIP 的关节专属属性为合法零值，并通过角色区分“不适用”与“数值为零”。joint limits 不进入 geometry encoder。

### 10.3 整手主干

首版使用 Pre-LN encoder-only Transformer。自注意力在实体层全连接，运动学图只通过无向最短路径、父方向、子方向、同分支和角色关系的 soft bias 注入；不构造 current all-pairs $SE(3)$ answer-like feature，不新增 COMMAND/HAND/LINK token。

同一次前向只含一个结构模式，固定 $N_E/N_J$，不使用 entity padding。不同结构模式分别形成 microbatch，并通过梯度累积共享同一参数更新。

### 10.4 零阶与一阶分支

整手主干输出零阶 token $z_i^{(0)}$。第一版一阶 head 按 canonical residual 路线实现：所有 JOINT 共用一个小型 head，读取对应 $[z_i^{(0)}\Vert f_i^{screw}]$，输出 $z_i^{(1)}$。PALM/TIP 不输出一阶 token。

结构性奇读取、额外 JOINT block、直接 encoder tangent 与 tangent distillation 是正交候选，不替换首版 residual 路线。若成对 joint-sign 测试发现 $f_i^{screw}$ 已丢失轴向正负，应修正 relation basis 或旋量分支，不允许从完全 sign-even 的 $Z^{(0)}$ 凭空恢复非零奇输出。

### 10.5 训练期解码器

密度解码器读取 owner token $z_g^{(0)}$ 与查询特征，使用 FiLM 条件残差多层感知机，最终 sigmoid 输出 $L$ 个密度通道。密度路径不读取 $z_i^{(1)}$，因为密度对 paired joint-sign rewrite 为偶。

$D_\kappa$ 读取 $z_g^{(0)}$、$z_i^{(1)}$、查询特征与 JOINT selector。首版先实现普通 conditional MLP 与固定 paired parity evaluation；对 $z_i^{(1)}$ 结构性线性的奇读取是候选。独立 $D_g$ 默认关闭。

## 11. 损失与实施顺序

首版联合目标为：

$$
\mathcal L_{SSL}
=
\mathcal L_{density}
+\lambda_\kappa\mathcal L_\kappa
+\lambda_g^{(\kappa)}\mathcal L_g^{(\kappa)}
+\lambda_{Sob}\mathcal L_{Sob}
+\lambda_{chain}\mathcal L_{chain}
+\lambda_{pair}\mathcal L_{pair},
$$

其中 $\lambda_\kappa$、$\lambda_g^{(\kappa)}$、$\lambda_{Sob}$ 与 $\lambda_{chain}$ 在完整首版为正，$\lambda_g^{direct}=0$。$\lambda_{pair}$ 是否进入训练是消融变量，但 paired parity test 固定存在。

为隔离故障，实施按以下顺序展开，但完整首版的科学语义不因此改变：

1. 只闭合 distance、multi-band density、$Z^{(0)}$ 和 density decoder。
2. 加入 residual $z_i^{(1)}$、显式 $\kappa$ 与由 $\kappa$ 派生的 $g$。
3. 加入同一 density predictor 的稀疏 Sobolev/JVP 与 chain consistency。
4. 完整强默认稳定后，通过置零单项或替换表征来源做归因消融。

各损失权重在固定 generated calibration batch 上按共享前端梯度量级校准，校准值写入 fully resolved config 后冻结。不能使用 official held-out loss 调整权重。

## 12. 技术栈与后端职责

### 12.1 核心主线

| 工具 | 职责 | 不承担 |
| --- | --- | --- |
| PyTorch | q 采样、批量张量、网络、自动微分、优化与日志张量 | URDF 语义猜测 |
| Warp | GPU 静态 mesh BVH、最近面、重心坐标、sign/source 与批量 target query | 离散最近面选择的训练反向 |
| trimesh | CPU 离线 mesh 读取、面积、采样候选和格式检查 | 训练循环高吞吐 query |
| Pinocchio | CPU FK/Jacobian reference | 生产 GPU 前向 |
| HPP-FCL | CPU distance/collision reference | 在线训练主后端 |
| Isaac Sim | URDF importer 与 runtime pose parity | SSL target generation 和训练循环 |

训练 query 先通过 $T_{hg}(q)^{-1}$ 变换到静态 owner-local geometry，再查询缓存 BVH；不为每个 batch 移动网格或重建 BVH。Warp target 输出 stop-gradient；网络的一阶自动微分只作用于 retained encoder 与 density decoder。

### 12.2 第三方候选

Kaolin 0.18.0 官方支持 PyTorch 2.7.0 与 CUDA 12.8，可提供 point-to-mesh squared distance、face index 与 distance type。本阶段允许在方案全部讨论完成后安装 Kaolin，用作单手距离、最近面和吞吐对照；比较通过前不进入核心依赖。

PyTorch3D 提供 surface sampling、farthest-point sampling、近邻与 point-face losses，但当前官方安装说明未覆盖 PyTorch 2.7.0，且接口不直接闭合 closest point barycentric/provenance contract。首版不安装、不进入核心路径，只记录为采样/覆盖候选。

首版不引入大型 CSG/Boolean 依赖。若同 owner component filtering 与目标 query 无法满足 surface truth、inside/outside 或 union-distance 合同，再在几何阶段单独评估 robust Boolean、voxel union 或 Kaolin/其他后端。

## 13. 配置、清单、缓存与日志

### 13.1 配置

复用现有 Hydra/OmegaConf，只使用浅层声明式配置：component-local schema 由 `representations`、`models` 与 `objectives` 各自拥有；`ssl/config` 组合 stage 约束；当前 `ssl/pretrain.py` 执行 fully resolved experiment，`ssl/experiments` 与 `ssl/runtime` 尚未承载独立实现。

禁止深继承、通用 Manager façade、trainer 内 field-specific `if/elif` 和依赖当前工作目录的路径。每次运行先保存完全解析配置，再创建模型、缓存和 optimizer。

### 13.2 渐进资产清单

资产清单分三档，三档只改变数据声明和抽样权重，不改变模型或目标接口：

| 档位 | 内容 | 作用 |
| --- | --- | --- |
| 单母体 | `right_t4_i4_m4_r4` pre-made mother | 资产、目标和单手过拟合闭环 |
| 小型广混合 | 均衡选择不同 pre-made topology、finger family、handedness 与少量 children | 模型、带宽和容量筛选 |
| 完整 generated | 广泛混合 pre-made/post-mutate、LEAP/Allegro/mixed fingers、变 DOF 与左右手 | 正式 generated 训练与留出证据 |

抽样层次固定为：先平衡 topology/family/handedness stratum，再选 pre-made root，最后选该 root 的 post-mutate variation。不能让资产数量最多的某一目录自然支配优化期望。

训练/验证至少区分：seen-topology/new-morphology、held-out pre-made root/topology、held-out family composition、DOF、handedness 和 worst-hand。兄弟 post-mutate variations 可以用于已见 topology 的 morphology 留出，但完整未见 topology 组必须连同全部 children 一起留出。

### 13.3 官方手协议

主结果的 SSL optimizer、超参数选择、checkpoint 选择与未来 PPO 全部只使用 generated assets。official LEAP/Allegro 适配器和 sidecar 可以提前实现并通过公式/位姿测试，但 official field loss 不得参与模型选择。

配置冻结后先执行 official zero-shot geometry evaluation。随后可从同一 frozen checkpoint 单独执行 geometry-only target-hand SSL adaptation；该结果必须标记为目标几何自监督适配，不能写成严格 held-out。

### 13.4 缓存与运行证据

资产事实保存在 versioned `hand.yaml`。派生 SSL 静态缓存使用 `NPZ + JSON`，至少记录 asset hash、schema version、backend/version、frame、unit、q_home、owner、anchor/home sample realization、query seed 和 split role。

训练不预生成 trajectory labels。训练时在线采 q/query/targets；固定 validation bank 在启动时物化并重复评估。当前 NPZ 保存 asset ID、latent、entity/joint/field/edge masks 与 density/κ dense error；完整 q/query/target/provenance 仍由 resolved config、manifest 和未来扩展 artifact 补齐。Warp compiled cache 与实验数据 cache 严格分离。

运行产物遵守：

```text
logs/geometry_ssl/<experiment>/<UTC timestamp>/
```

TensorBoard 保存在线动态；当前 JSONL 保存 step、split、asset IDs、五项损失、总损失与训练梯度范数；当前 NPZ 保存 latent、四类 mask 和 density/κ dense error。owner、query stratum、distance shell、bandwidth 与 gauge 分层属于后续 analysis schema。

## 14. 数值候选与选择规则

以下数值不在总规范中假装固定。实现必须使用预先声明的候选和 generated-only promotion metric：

| 变量 | 首轮候选 | 主要选择指标 |
| --- | --- | --- |
| 每指 anchors 数 | 5、10、20 | 支撑覆盖、手性统计稳定性、重网格稳定性、延迟 |
| anchor surface/interior 比例 | 纯表面、表面占多数、各半 | anchor realization 稳定性、field reconstruction、held-out morphology |
| anchor radius | palm projected scale/mount spacing 的少量无量纲比例 | 不同 palm source 的非空支撑、连续性与覆盖 |
| 每 owner home 点数 $M_g$ | 32、64、128 | surface coverage、最小 bandwidth、留出误差、显存 |
| 每 owner query 数 $N_Q$ | 32、64、128 | Monte Carlo 方差、依赖性诊断、显存与吞吐 |
| bandwidth | 2、4、8、12、20、32、48、64 mm 中选 3–4 个 | fine/link-tip/palm-mount shell 覆盖与留出误差 |
| $D_0$ | 96、128、192 | 留出密度、latent permutation gap、激活显存 |
| $D_1$ | 32、64、96 | $\kappa/g$、奇偶误差与一阶成本 |
| 主干深度 | 2、3、4 层 | 等预算下的误差—成本曲线 |
| decoder | 2/3 层，128/256 hidden width | query-only baseline gap、留出 error 与训练成本 |

参数筛选顺序固定为：无网络几何 probe、单手 tiny overfit、小型广混合训练、generated held-out selection、official frozen evaluation。不能在 official 结果出现后回头更改 candidate grid 或 promotion rule 而仍称其为严格留出。

## 15. 必需诊断与停止条件

密度训练至少执行：仅查询点解码器、固定查询不同 q、同手跨 q latent permutation、固定稠密 query grid、按 owner/stratum/band/shell 的误差和重网格压力测试。

一阶训练至少执行：$z_i^{(1)}$ 置零、跨 JOINT 打乱、符号翻转、ancestor/non-ancestor 分层、解析/有限差分、$SO(2)$、joint-sign paired rewrite、随机方向 JVP 和最近点切换占比。

任一候选满足以下条件时停止进入更昂贵阶段：

- 不能通过解析公式、有限差分、frame/unit 或 gauge contract；
- owner coverage 不能 fail closed 或存在重复/缺失 collision pieces；
- query-only baseline 接近完整模型；
- $Z^{(0)}$ 对固定 query 下真实 q 变化不敏感；
- $z_i^{(1)}$ 只有退化为零才能满足奇偶测试；
- held-out generated hands 明显劣于更简单基线；
- target backend、retained encoder 或高阶自动微分成本不可接受。

### 16.2 测试所有权

## 17. 分阶段实施路线

### 阶段 0：工程规范与文档同步

完成本规范、目录索引和已知文档漂移清单。不得新增训练入口、配置类、registry 或 placeholder test。

### 阶段 1：资产语义与机器人接口

更新 `hand.yaml` schema、pre-made/post-mutate 来源、owner lowering、q_home、mount seed、碰撞事实和纯张量运动学。先支持 specified mother，再支持小型 generated mix。

验收：mother 的 24 个 collision pieces 完整唯一覆盖；frame、mount rotation、fixed descendants、q_home 与 FK/point Jacobian 合同通过。

### 阶段 2：几何真值与 target backend

实现 owner union surface candidates、anchor/home/query sampler、Warp closest-point/provenance、primitive reference 与 Kaolin 对照。此阶段不训练网络。

验收：距离、closest source、surface sampling、inside/outside capability、非光滑 mask、gauge、重网格、确定性和吞吐通过。

### 阶段 3：单资产零阶 SSL

闭合指定 mother 的 online q/query/target、point–anchor encoder、owner encoder、whole-hand backbone、density decoder、objective、checkpoint 与 diagnostics。

验收：tiny overfit、fixed-query q sensitivity、query-only baseline gap、latent permutation gap 和分层 field error 通过。

### 阶段 4：generated 广混合零阶 SSL

按三档 manifest 扩展到 topology/family/handedness/post-mutate mix，完成 capacity/bandwidth/sampling selection 与 LEAP-only matched baseline。

验收：seen-topology/new-morphology、held-out topology/family、worst-hand、左右手和成本均有可审计结果。

### 阶段 5：一阶运动学—几何 SSL

加入 residual $z_i^{(1)}$、$D_\kappa$、derived $g$、稀疏 Sobolev/JVP 与 chain consistency，再做表征来源和监督关闭消融。

验收：解析/有限差分、ancestor zero、paired parity、held-out kinematics、latent usage 与高阶成本通过。

### 阶段 6：official 严格留出与几何适配

冻结 generated config/checkpoint 后评估 official LEAP/Allegro；再从同一 checkpoint 做 geometry-only adaptation 候选。

验收：zero-shot 与 adaptation 分开报告；语义 sidecar、owner coverage、frame、scale 和 source provenance 可审计。
